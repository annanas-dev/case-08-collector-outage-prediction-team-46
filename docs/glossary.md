# Глоссарий

Термины из раздела 1 ТЗ плюс сокращения, которые встречаются в данных.

## Предметная область

| Термин | Значение |
|---|---|
| Коллектор | подземное инженерное сооружение для размещения коммуникаций |
| Москоллектор | АО, эксплуатирующее коллекторы Москвы, заказчик данных |
| ОДС | объединенная диспетчерская служба |
| СМВУ | система мониторинга и высокоуровневого управления, источник журнала событий |
| ЦУ КГХ / КГХ | Центр управления Комплексом городского хозяйства |
| Эксплуатационное подразделение | районное подразделение, отвечающее за свой набор коллекторов (в данных: «Район по эксплуатации») |
| Пикет (ПК) | участок работ; в названиях каналов `ПК746` означает положение датчика вдоль коллектора |
| Вентшахта (ВШ) | вентиляционная шахта |
| Теплотрасса | трубопроводы теплоносителя |
| ТО / ППР | техническое обслуживание / планово-предупредительный ремонт |
| Регламентные сроки | установленные периоды обслуживания |
| РТЭК | Регламент технической эксплуатации коммуникационных коллекторов |
| Реестр оборудования | учетный список технических средств |
| Заявка | документ для планирования ремонтных и иных мероприятий |
| СКУД | система контроля и управления доступом |
| Фактическое состояние | реальное техническое состояние оборудования |

## События и прогноз

| Термин | Значение |
|---|---|
| Инцидент | событие мониторинга: отклонение датчиков или оборудования от рабочего или планового состояния |
| Критический инцидент | событие, угрожающее жизни человека |
| Отказ датчика | выход измерительного устройства из строя (в ТЗ: его прогнозирование) |
| Ложное срабатывание | ошибочный тревожный сигнал |
| Несанкционированный доступ (НСД) | попытка незаконного проникновения |
| Паттерн | устойчивый шаблон поведения или последовательность событий |
| Горизонт прогноза | период, на который делается предсказание (по ТЗ ≥ 24 ч) |
| Предиктивная аналитика | прогноз будущих событий по данным |
| Inference | применение обученной модели к новым данным |
| Precision / Recall | точность / полнота предсказаний |

## Типы датчиков

| Термин | Значение |
|---|---|
| Контактные датчики, КД | обнаружение физического контакта: КД Дверь, КД Люк, КД АВ |
| Объемные датчики, ОД | датчики движения и присутствия |
| Газовые датчики | анализаторы газовоздушной среды |
| Дымовые датчики | детекторы задымления |
| Температурные датчики, ТД | измерители температуры; «Тепловой датчик» относится к пожарной охране |
| ИБП | источник бесперебойного питания |
| АНС | автоматическая насосная станция |
| УИР-Р | устройство пожарной охраны (в данных «Состояние УИР-Р») |
| Силовые кабели | кабели для передачи электроэнергии |

## ИТ

| Термин | Значение |
|---|---|
| RBAC | доступ на основе ролей |
| LDAP / AD | протокол и служба каталогов для корпоративной аутентификации |
| TLS | шифрование трафика, по ТЗ версия 1.2+ |
| Питч-сессия | презентация проекта перед экспертной комиссией |
